# Модель данных

## Источник

Source — зарегистрированный внешний источник: ID, название, тип, постоянный адрес,
параметры получения, AutoRefresh, запрет публикации и SyncState.
Внешняя идентичность источника неизменяема. Изменение названия отражается в атрибуции.

SyncState хранит дату последней попытки получения, дату последнего успешного получения
и описание ошибки. Состояние получения не определяет доступность последнего успешного
содержимого. Секреты Telegram задаются конфигурацией, а не параметрами источника.

## Страница

Page — страница сайта с ID, Path, Title, Description, MachineContext, Language, Status,
CreatedAt, UpdatedAt, PublishedAt и упорядоченными Blocks.

Title — единый заголовок HTML, Markdown и метаданных. Description — обычный текст
для описания и превью; автоматически в содержимое страницы не добавляется.
MachineContext — необязательный публичный контекст для машинных потребителей.
В HTML он доступен через метатег wcs-guide:machine-context, в Markdown — отдельным разделом.
В основной визуальный текст и описание превью MachineContext не включается.

Path — канонический незакодированный локальный путь с поддержкой Unicode.
Валидация исключает конфликт со служебными маршрутами и Markdown-представлениями.
Статусы — черновик и опубликованная страница. Даты хранятся в UTC, порядок дат не проверяется.

## Блок

Block — ручной Markdown-блок или импортируемый блок. Страница допускает произвольную
композицию блоков. ImportSettings содержит идентификатор источника и ExtractionRules.
TextAnchor задаёт обычную подстроку и включение содержащей её строки.

PreparedContent хранит Content и PreparedAt — последний успешно импортированный Markdown
и время его получения. nil означает отсутствие успешного результата. Снимков оригиналов,
истории содержимого, контрольных сумм, редакций и токенов актуальности нет.

Оригинал обрабатывается в памяти. Успешный результат заменяет предыдущий; ошибка оставляет
прежний результат. Изменение якорей сохраняет содержимое до успешного нового импорта.
При замене источника прежний результат блока очищается.

## Хранение и публичное чтение

SQLite содержит sources, pages и blocks. Последний импорт хранится непосредственно
в blocks.imported_content и blocks.imported_at. NULL означает отсутствие результата.
Используются STRICT и внешние ключи. Исходные публикации в БД не сохраняются.

Редакторское сохранение страницы не перезаписывает импортированный текст. Запись результата
проверяет существование блока и его принадлежность источнику. Контроля конкурентных редакций
нет: последняя успешная запись заменяет предыдущую.

Публичные потребители используют PublicPage, PublicBlock, PublicPageSummary,
GetPublicPage и ListPublicPages. Черновики и заблокированные материалы исключаются.
Публичность результата определяется статусом страницы и текущим запретом источника.

public_updated_at меняется при изменении публичного текста, метаданных, атрибуции,
состава или порядка блоков. Повторный импорт одинакового Markdown дату не меняет.
Сохранение и пересчёт дат затронутых страниц выполняются одной транзакцией.

Основные сущности реализуют slog.LogValuer; содержимое и секреты в логи не включаются.

## Состояние автоматического импорта

Интервал общий и хранится в конфигурации приложения. AutoRefresh включает источник в цикл;
PublicationBlocked независимо запрещает публичный показ. blocks.import_error хранит последнюю
ошибку подготовки; успех её очищает. Поле не публикуется и не журналируется через LogValue.
При сохранении результата сравниваются текущие параметры источника и правила блока.
Это проверка значений настроек без истории и номеров редакций.
