# WCS Guide

[WCS Guide](https://wcs.guide) — публичный информационный ресурс сообщества West Coast Swing.

Лицензия: [GNU AGPL v3](LICENSE) (`AGPL-3.0-only`).

Источники с включённым автоматическим обновлением синхронизируются последовательно.
REFRESH_INTERVAL задаёт паузу между циклами в минутах; по умолчанию — 10.
Подробности — в [инструкции разработчика](docs/development.md#автоматическое-обновление).

Редакторский интерфейс и вход через Passkey: [настройка доступа](docs/auth.md).
Локально публичный сайт — http://127.0.0.1:8080, редактор — http://localhost:8080.
