# История изменений

## Unreleased

- Telegram подключается при запуске; ошибки подключения не прерывают работу сайта.
- Все Telegram-реквизиты и путь к сессии обязательны; ручной импорт перенесён в tools.

- Импорт заменяет последнее успешное содержимое блока без хранения оригиналов и истории.

- Источники автоматически обновляются с общим интервалом REFRESH_INTERVAL.
- Сохраняется последняя ошибка подготовки блока; ошибки не скрывают прежний материал.

- Добавлен защищённый редакторский контур с Passkeys, серверными сессиями и двумя ролями.
- Администратора можно создать и восстановить командами admin bootstrap и admin recover.
